# O3SM

> **Note:** This project is a simple, quick-and-dirty AWS SSM Parameter implementation compatible with boto3.  
> It is intended for development purposes only. **Use at your own risk!**
>
> The project is based on the [full-stack-fastapi-template](https://github.com/fastapi/full-stack-fastapi-template) and retains all its features and structure.

O3SM stands for Open-Source SSM.
